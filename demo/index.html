Component Prototype Builder helps designers build VA prototypes from approved design system parts, ready for user testing and engineer review.

The Challenge

Getting a workable prototype to user testing takes too long.

Prototypes drift from the VA Design System, and nobody sees it until review.

Engineers find the gaps after the prototype is built.

Each round of fixes pushes testing later.

The Oddball Solution

Meet Component Prototype Builder: build VA pages from the components VA already approves.

Designers describe what a Veteran needs to see. The builder lays it out with VA Design System parts and checks the work as they go.

How Designers Build

Designers work in three places.

Pages. Start from a template and edit each block. Spacing comes from the VADS scale, and the heading outline is checked as you go.

Components. Describe a component and the builder lays it out from VADS rules. Change it until it is right, then save it to the study.

Forms. Describe a form and it comes back as chapters and pages that follow VA forms patterns.

Know What VA.gov Uses

Designers see how VA.gov already uses each component.

Where it is used. The products that use each component.

States. Each state, shown with the real VA web components.

Accessibility. Guidance for each component.

Props and code. The markup, ready to copy.

How Engineers Review

Engineers get what they need to decide before a build starts.

Specs. The components, layout and states behind each page.

Data. Where each value comes from, set field by field. Anything left on its default becomes a question.

Go or no-go. Mark each system feasible or not, answer open questions, and send the decision back to the designer.

How It Fits Together

From idea to Prototype Kit in four steps.

Build. Make components and forms and save them to the study.

Compose. Place them on a page that uses the kit header, footer and page items.

Review. Send a version to engineering for a go or no-go.

Export. Download a bundle and drop it into the VA Prototype Kit.

What It Checks For You

Mistakes show up while you build, not at review.

Heading order, spacing on the VADS scale and VADS-only parts are checked as designers work.

Designers and engineers work from the same prototype, so one that follows the VA Design System from the first click is faster to test and easier to trust.
